  RPC（Remote Procedure Call，远程过程调用）框架是一种用于实现分布式系统中不同节点之间通信的技术。它的主要作用是让位于一个计算机上的程序能够调用另一个计算机上的子程序或函数，而无需开发人员了解底层网络通信的细节。RPC框架的核心思想是使网络通信像本地调用一样简单，提高开发效率和代码的可维护性。
